# Version 12.0.0

## New features

- Containers appear as Firefox tab groups in the tab bar. Each container's tabs form one group, with the container's name and color. Renaming or recoloring either one updates the other, and hiding a container collapses its group. ([#111](https://github.com/menhera-org/TabArray/issues/111), [#32](https://github.com/menhera-org/TabArray/issues/32))
  - This is on by default. To turn it off, open the extension's settings and clear **Show containers as Firefox tab groups** on the **General** tab. Turning it off ungroups the tabs, and the tabs of collapsed groups are hidden as before.
  - While it is on, index tabs are not used.
  - Firefox for Android has no tab groups, so nothing changes there.
- Temporary containers left over from an earlier session are removed at startup.

## Removed

- Tags are gone. Containers now appear as tab groups in the tab bar, which cannot show tags inside them, so containers and container groups are the one way to group tabs. Updating deletes your saved tags, and tabs keep their order inside each container.

## Improvements and fixes

- Firefox 140 or later is required (Firefox for Android 142).
- The extension's pages were rebuilt with React 19. ([#174](https://github.com/menhera-org/TabArray/issues/174))
- Fixed a memory leak that could make Firefox stop responding. ([#139](https://github.com/menhera-org/TabArray/issues/139))
- User-agent overrides now also apply to pages served by a service worker. ([#396](https://github.com/menhera-org/TabArray/issues/396))
- Sites no longer see `navigator.userAgentData` unless a container overrides the user agent, which broke some sites and sign-in pages. ([#645](https://github.com/menhera-org/TabArray/issues/645))
- The sidebar's close-window button asks before closing the window. ([#508](https://github.com/menhera-org/TabArray/issues/508))
- "Edit container" works for containers without an icon, and supports the container colors of Firefox 153, including violet. ([#646](https://github.com/menhera-org/TabArray/issues/646))
- Links from other apps no longer open twice with the "last active container" option. ([#411](https://github.com/menhera-org/TabArray/issues/411))
- Request headers no longer pass through the extension unless a container overrides the language or user agent.
- The Chrome user-agent preset follows Chrome's two-week release cycle.
- The Cookies page no longer fails on data stored by sandboxed pages.
- Listings of the extension's own folders work again in Firefox 152 and later.
- New documentation explains how to use Microsoft single sign-on in containers. ([#552](https://github.com/menhera-org/TabArray/issues/552))
- Translation updates.
- Dependencies updates.

Download and install from: https://addons.mozilla.org/firefox/addon/container-tab-groups/
